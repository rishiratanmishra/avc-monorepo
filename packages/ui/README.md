# `@repo/ui`

Starter-level React primitives shared by the Turborepo template. This package is **not** the AVC production design system yet.

Do not use these components in product surfaces without a review that promotes them into the documented design system. App-local primitives under `apps/web/components/ui/` are currently the closer reference for product UI, but they also remain subject to `docs/design-system/standards.md`.

Canonical rules:

- `docs/design-system/standards.md`
- `docs/architecture/standards.md`
- `packages/ui/AGENTS.md`

Use `yarn lint`, `yarn check-types`, and `yarn build` to validate changes.
